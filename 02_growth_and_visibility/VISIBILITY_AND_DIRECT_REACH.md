## 0. Get round the taboo by leading with what you are, not the label
Clubs (and Meta's ad rules) react to "project assistance" because it sounds like *"we do your project"*. You also sell **kits, components, 3D printing, PCB, tools, mentoring and internships**, and those things aren't taboo.

| Where | Lead with | Project help appears as |
|---|---|---|
| Bio, website hero, ads, anything public-facing to institutions | **"Engineering projects: learn it, build it, own it."** Kits · 3D printing · PCB · tools · mentoring | "Final year project **mentoring**: we build it *with* your team" |
| Fest sponsorship / maker community | **The Project Shop store:** components, kits, 3D printing (normal commercial sponsorship) | not mentioned |
| DMs / consult | Full offer (₹15K+, class, internship) | the main service |

Same company and the same honest offer, just with the entry point students and institutions are comfortable with. **Never** say "we'll do your project", "readymade project" or "submit-ready". That wording is also what gets ads rejected (Meta bans ads for "products that enable cheating").

## 1. Visibility: be found whenever anyone searches (top priority)

Students search in 3 places: **Google (and Maps), Instagram search, YouTube.** Be the clear result in all three.

### A. Google + Maps (biggest gap: no dedicated project centre showed up for Kottayam/Kollam searches)
1. **Google Business Profile** (free): real name "The Project Shop" (no keyword stuffing), **service-area business** (hide the address if no storefront), service areas Kottayam · Ernakulam · Kollam. Category: closest of *Engineering consultant / Educational consultant / Electronics company* (choose in the dashboard). Add phone/WhatsApp, hours, the consult link, real photos (workshop, 3D printer, builds).
   - Use one profile, with a real address only. Fake addresses for extra cities lead to suspension.
2. **Reviews:** ask this year's **5 clients** for a Google review *now* (send the direct review link, it takes 1 minute). Reviews are an official ranking factor, and 5 is a start. Then ask every client at handover.
3. **Replace the "Coming Soon" site** (it currently has nothing Google can rank):
   - Home: what you do, the offer, WhatsApp button, "Book free 1-hr consult"
   - Service pages: Final year project mentoring · IoT · Robotics · Hardware + simulation · M.Tech · Kits/3D printing/PCB
   - **City pages:** "Final year project mentoring in **Kottayam**" / **Kochi** / **Kollam–Karunagappally**. Each page has to be genuinely different (nearby colleges, how the consult works, sample projects)
   - FAQ (price ₹15K–25K, what's included, "do you do it for us?" → "no, we build it with you")
   - Schema (LocalBusiness/ProfessionalService + Service) with name/phone identical to the Business Profile. Register with **Google Search Console** + submit the sitemap
4. **Free directory listings** with identical name/phone: JustDial, Sulekha, Quickerala, Bing Places, Apple Maps, a Facebook page. **IndiaMART** for kits/components later. (Free tiers mean sales calls. Ignore them.)
5. **Check rankings yourself monthly:** on your phone in incognito, search "final year project centre Kottayam / Kochi / Kollam", "KTU main project help", "IoT projects Kochi", and note who's in the map pack.

### B. Instagram search
| Field | Set it to |
|---|---|
| Username | `theprojectshop.online` (matches the domain) or similar |
| **Name field** | `The Project Shop \| KTU Projects` (widely believed to be searchable, and it costs nothing) |
| Bio | `KTU final year project mentoring 🛠️ · CS · EC · EEE · Robotics · IoT · Kottayam · Kochi · Kollam · Free 1-hr team consult 👇` |
| Settings | Professional account, public, **"Allow public photos and videos to appear in search engine results" ON** (Google indexes your posts) |
| Every post | First caption line = a search phrase ("KTU S7 mini project ideas ECE") · **location tag** (Kottayam/Kochi/Karunagappally) · ≤5 hashtags (#ktu #ktuprojects #btechprojects …) · alt text · keyword in on-screen text and speech |

Instagram's search mainly matches **your text** (username, bio, captions, places), then ranks by engagement. So every caption should read like what a student would type.

### C. YouTube search
No Malayalam channel covers KTU project ideas or Arduino/ESP32 (earlier scan). Title format: **"IoT final year project idea for ECE | KTU | Malayalam"**. Every video description has the website + WhatsApp. YouTube videos also show up in Google results.

**Brand search test:** when someone Googles "The Project Shop Kerala", the first page should show the website, Maps profile, Instagram, YouTube and JustDial. Use the same name, logo and phone everywhere.
