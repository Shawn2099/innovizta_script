# Manglish guide: turning the English meaning into Shawn's own lines
One page. Use it the day before every shoot, when Shawn writes his lines in the Notes app (run sheet §0).
**Rule zero:** the script's Manglish is only a hint, because AI Malayalam sounds unnatural. Shawn's natural way of saying it always wins, **as long as the meaning, order and facts stay the same.**

## 1. Which words stay in English
Keep these in English, always: they're how KTU students actually say them, and they match the on-screen text.
- **Numbers, dates, amounts:** "30 teams", "100 points", "November 30", "2027 pass-outs". Say exactly what's on screen.
- **KTU / college words:** project, review, Review 1, viva, panel, Phase II, S7/S8, internals, Faculty Advisor (FA), HoD, portal, notice board, CGPA, activity points
- **Tech words:** circuit, sensor, ESP32, board, code, parts list
- **Brand + keywords:** The Project Shop, INTERN, PROJECT, consult, internship, fellowship
**Malayalam is for** the feeling and the glue: "ninte", "alle?", "poyi nokku", "athaanu", "venel", "theerno?"

## 2. Sentence rules
1. **Max ~10 words per sentence.** Two short sentences beat one long one.
2. **Start with the strongest word** (the number, the fear, the name): "**100** activity points theerno?", not "Ninte activity points ethra aayi ennu…"
3. **Speak, don't write.** Use spoken forms, not textbook Malayalam: "venam", not "aavashyamaanu"; "pattilla", not "saadhyamalla".
4. **Neutral central-Kerala Manglish.** Our viewers are in Kottayam, Ernakulam and Kollam. Avoid words that only one district uses.
5. **"Bro / machane"** once per reel is enough. Every line = sounds forced.
6. **No new facts.** If you want to add an example, it must be true for us (your own experience). Never add a number that isn't in the fact sheet.

## 3. The 3-minute self-check (per reel, the day before)
- [ ] **Say each piece out loud once.** If you trip on a line twice, rewrite it shorter.
- [ ] **Time the hook (B1):** under 3 seconds.
- [ ] **Every key word on screen is also spoken**, e.g. on-screen "ZERO FEES" ↔ spoken "fee illa".
- [ ] **Read it to the helper:** "does this sound like a senior talking, or like an ad?" If it sounds like an ad, simplify.
- [ ] **Numbers and dates** match the fact sheet exactly.
