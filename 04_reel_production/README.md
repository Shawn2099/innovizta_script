# 04_reel_production: making the reels

| File / folder | Purpose |
|---|---|
| `SCRIPT_PLAYBOOK.md` | **How to write a reel that works:** 15 laws (our data + books + skills + big-page validation), audience lens, 8-step writing procedure, 15 hook templates + 12-point hook score, Script QA (100) + ethics gate, trend tactics, worked example |
| `REEL_SCRIPT_TEMPLATE.md` | **The global template.** Part A: sets, camera, frame, posture codes · Part B: editor codes (safe zones, text, cuts, sound, **transitions, clip durations, overlays, cover**, tooling notes) · Part C: beat timings + hook patterns · Part D: the script sheet (copy it for each reel) · Part E: 7 formats · Part F: shoot rules · Part G: QC |
| `CONTENT_CALENDAR.md` | Dated posting/shooting plan + status per reel: the source of truth for "today's content" |
| `series/OPPORTUNITY_DROP_FORMAT.md` | Opportunity Drop series details: sources, verification checklist, info card, ManyChat DM text (shooting/editing specs = template F3) |
| `scripts/` | One file per reel: `<post date>_<REEL NAME>_<topic>.md`, a filled copy of template Part D (first: `2026-11-16_LAUNCH1_why-we-started.md`) |

Workflow: brief + hooks + gates (SCRIPT_PLAYBOOK §3) → pick the series + format (Part E) → copy Part D into `scripts/<post date>_<REEL NAME>_<topic>.md` → fill it in → Shawn shoots from the shoot list → editor cuts from the shot table/YAML → QC (Part G) → post.
