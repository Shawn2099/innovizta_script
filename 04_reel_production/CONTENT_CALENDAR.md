# Content Calendar (living): what to post/shoot on which day
Source of truth for "what's today's content?". Update the Status column whenever a script is written, shot, edited or posted.
Rules: `01_strategy/6_MONTH_PLAN.md` (monthly theme + CTA) · weekly rhythm below · scripts in `scripts/<post date>_<REEL NAME>_<topic>.md`.

## Standard week (from launch)
| Day | Post | Work |
|---|---|---|
| Mon | **PIW** Project Idea of the Week (keyword PROJECT), or STO during launch | write the week's scripts |
| Tue | stories only | **batch shoot day** (all reels of the week + YouTube when due) |
| Wed | **SRV** B.Tech/M.Tech Survival | edit |
| Thu | carousel (from Wednesday's SRV topic) | edit, ManyChat text |
| Fri | **DROP** Opportunity Drop #__ (keyword INTERN) | — |
| Sat | **AIB** AI/build in public (keyword TOOL), or **HUM** | YouTube upload (alternate weeks) |
| Sun | stories (poll) | **review** last week's numbers |
Nov 2026 is a setup month: 3 reels/week (Mon/Wed/Fri). 4/week from December.
