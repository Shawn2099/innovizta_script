# scripts: one file per reel
Name: `<post date YYYY-MM-DD>_<REEL NAME>_<topic>.md`, e.g. `2026-11-16_LAUNCH1_why-we-started.md`, so the folder sorts in posting order. Reel name = series word + number (LAUNCH1, SURVIVAL2, DROP1, IDEA1); it is also the tracking code and the clip prefix. Content: a filled copy of `../REEL_SCRIPT_TEMPLATE.md` Part D (header + shot table + shoot list + YAML editor block).
After posting, add at the bottom: post date, link, and 48-hour stats (views, watch %, sends, saves, keyword comments).
