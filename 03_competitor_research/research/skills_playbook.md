# Script and Hook Playbook: single host, phone + tripod, Manglish Reel, Kerala engineering project mentoring

Condensed from the installed skills. Tags: [HW] hook-writer, [SFS] short-form-video-script (WATCH), [TH] talking-head-and-piece-to-camera (TAKES), [VRE] viral-reverse-engineering, [RS] reels-scripting, [IG] instagram-growth, [MV] marketing-skills:video.
Note: the skills' numbers (50-60% drop-off in first 3s, 80% mute, 3x layered hook, sends 3-5x likes) are secondary-source and the skills themselves say "verify quarterly". Treat as directional.

## 1. Core principles
- Metric that matters is watch-through, then sends (DM shares) and saves, not likes [SFS, IG]. Sends-per-reach: about 1-2% solid, 3%+ unlocks non-follower reach [IG].
- A hook opens a real gap; the content must pay it off. Hook is mined from the truest, most surprising/specific fact in the content, not bolted on [HW].
- Truth kept = reach. Overpromise creates a mid-video retention cliff and bounce [HW, SFS].
- Presence beats polish; audio beats image; take 2 usually beats take 9 [TH].

## 2. Hook mechanisms (11) [HW]
Curiosity gap, contrarian/pattern interrupt, stakes/cost, specificity/numbers, identity callout, in-media-res story, mistake/negativity, transformation, question, timeliness, authority/proof. Failure mode of every one: gap not paid off / fake number / fake urgency.
Pick by goal: reach = contrarian, story, relatable specificity; comments = question, contrarian; saves = specificity, authority, mistake-lesson; trust/conversion = transformation, authority with real proof [HW].
Generate 5-10 across different mechanisms, score, keep 1-2; most should die [HW]. Ship 5 hook variants over the same body to test [SFS].

## 3. Fill-in-the-blank hook templates (Kerala engineering project context)
Replace blanks with REAL facts only.
1. Stakes/cost: "Ee one mistake [X] kondu [N] students-nte final year project reject aayi."
2. Specificity: "[N] days-il [project] complete aakki [result], budget [Rs. N] mathram."
3. Identity callout: "Nee [branch] [semester] aanenkil, ith kandittu mathram project topic edukku."
4. Contrarian: "[Common advice, e.g. 'IEEE paper copy cheyyuka'] aanu ninte project kollunnath."
5. Mistake: "Njangal [N] projects guide cheythu; [N]% students ee [mistake] cheyyunnu."
6. Problem-first (visual): show [bad thing, e.g. a failing circuit/error screen] + text "[why it fails]" then "ith ninte project aanenkil nilkku."
7. Payoff-first (visual): show working demo + "ith [N] [days/hours]-il [how], ente vazhi ithaan."
8. Numbered: "Final year project-ile [N] mistakes, [N]-th aanu ettavum risky."
9. Transformation: "[Student/anonymous case] [bad state] to [good state] in [time], ithu enthu maatti."
10. Question: "Viva-yil ee oru chodyam [X] kettal ninakku answer undo?"
11. In-media-res story: "Submission-nu [N] divasam munp project [failure] aayi. Pinne [what happened]."
12. Curiosity gap: "Ninte guide parayilla, pakshe viva-yil [thing] chodikkum."
13. Authority/proof: "[N] projects [real outcome] kandappol [pattern] ethra common aanennu manassilaayi."
14. Timeliness (only if true): "[Deadline/event]-nu munp [N] things project-il tick cheyyanam."
15. Negative flip: "[Popular project idea] pazhaya idea aanu, [reason]. Pakaram ithu try cheyyu."
Rule from [RS]: don't open with "I"; start with "this/you/a fact/a name." (British-English/no-em-dash rules there are the skill author's style, not ours.)

## 4. First 3 seconds rules [HW, SFS, TH, IG]
- Most striking frame on screen before first word; start mid-action, mid-energy. No logo, no "hello friends", no breath/settle, no slow zoom.
- Layer the hook across three channels: visual + on-screen text + first spoken line. Text and speech reinforce, not duplicate verbatim. Must work muted.
- One short, specific, bold sentence; outcomes, numbers, contrasts, not vague topics.
- Read the hook alone: would a stranger need the next beat?
- Film the hook first and fresh each session (energy highest) [TH].
- Anti-patterns: throat-clearing, greeting, describing the asset, vague "you won't believe", giving away the payoff, too-broad address ("everyone"), template-by-rote [HW].

## 5. Script structure and timing (15-35s sweet spot; ~75 words = 30s) [SFS; RS says 30-45s, 2 points max]
| Time | Beat | Notes |
|---|---|---|
| 0-3s | HOOK (visual + text + spoken) | one claim, one gap |
| 3-6s | Bridge | open a loop ("ithinte reason last parayam") |
| 6-22s | Body: 2-3 numbered points | visual change every 2-4s; no shot over ~8s; each line must grab, teach, or set up payoff (cut-test) |
| 22-28s | PAYOFF | exactly what the hook sold; best point last |
| 28-32s | CTA + loop | one CTA ~2s; last line flows back to first frame |
Write as aligned beats: [time] VISUAL / ON-SCREEN TEXT / SPOKEN [SFS]. Write the muted version first.

## 6. Delivery direction (talking to camera) [TH]
- Phone at eye level, lens at top, facing biggest window (never behind you), mic within ~60cm or cheap wired lav, quiet room first. 9:16, eyes in top third, hands in frame, keep caption-safe zones clear. Shoot 4K for punch-in room.
- Memorize the map: 3-5 beats + first line and last line verbatim; riff the middle. No reading (eyes show it). If words won't stick, rewrite them to be more spoken.
- Start already talking. Talk to ONE person (a specific student). Smile just before speaking. Run at +20% energy; gesture.
- Retake per beat not per video; clap between takes; three-strike rule (a line failing 3x is a writing problem); ship good-enough, cap 3 takes/beat.
- Batch 4-8 scripts per session, hardest first, stop at 60-90 min, swap tops/shirts so posts do not look same-day.
- Self-review (agent cannot see footage): hook lands in 2s? audio clean? eyes on lens? sounded like me? would I keep watching on mute?

## 7. Retention devices [SFS, HW, MV]
- Open loop early and number points so progress is visible ("step 2 of 3").
- Pattern interrupts every 2-4s: cut, punch-in zoom, B-roll/screen capture, SFX, text pop.
- Cut-test every line. Hold the payoff-promise: don't give away the answer in line one; place payoff late but not past ~80% of runtime.
- Read the curve: 0-2s dip = weak promise (fix hook/first frame); mid cliff = dead air (tighten, add interrupt); end spike = loop worked (repeat it).
- Engineered loop: final line flows into frame 1 so replays feel natural.

## 8. CTA and share triggers [IG, VRE, SFS]
- One fitting CTA of ~2s tied to value; never "like and subscribe".
- Send triggers: relatable ("this is so us"), useful reference (checklist), conversation starter, identity/values, surprising/funny. Ask pre-post: who sends this, to whom, why? [IG]
- End on a line worth forwarding ("send this to your project partner"). Soft share prompt only when content already earns it.
- Package practical content as a resource for saves ("save this before you choose your topic").
- Share-driver psychology [VRE]: identity, high-arousal emotion (awe, anger, anxiety, amusement), social currency, practical value, relatability, trigger/topicality, story. A competent hook with no share-trigger = views, not virality.
- Comment-keyword CTA (single caps word) only if a real deliverable and working automation exist [RS].

## 9. Ethics and honesty rules [all]
- Hook must be true; no bait-and-switch; no fabricated stats, results, testimonials, or "N students" numbers [HW, SFS].
- No guarantee of virality or results; no buying followers [IG, VRE, SFS].
- Mechanism not surface: do not copy a competitor's script, footage, or music; inspiration not plagiarism [VRE, MV].
- Consent for anyone else on camera; disclose AI voice/visuals; avoid outcome guarantees (marks/placement) in line with YMYL caution [SFS, TH].
- Original, no TikTok watermark, native upload; clear niche for algorithm categorization [IG].
- Don't invent metrics from reference reels; one viral post is an anecdote, need 10+ examples to call a pattern; check account-size, luck, one-time-moment, survivorship confounds [VRE, RS].
- Do not shame camera-shy people; no gear purchases as the fix [TH].
- No fear-mongering in the opening line [HW].

## 10. Rubrics and checklists
**Hook score (0-2 each, max 12) [HW]:** Gap, Specificity, Truth, Fit (inside 3s / cutoff), Voice, Pull.
Truth and Pull are pass/fail gates: Truth=0 or Pull=0 disqualifies regardless of total. Fast pass: (1) would a stranger need the next beat? (2) will content deliver? (3) specific? (4) sounds like us?
**Script QA (reels-scripting, 100 pts, gate 95) [RS]:** source accuracy 30, user voice 25, hook and structure 20, spoken duration and clarity 15, caption/CTA consistency 10. Common violations: opens with "I", 3+ staccato fragments, states the conclusion, over 45s read aloud, 3 points instead of 2, caption does not mirror script.
**WATCH check [SFS]:** W striking frame + layered hook; A arc with loops and visual change; T works muted; C payoff cashed; H loop plus one CTA.
**Viral teardown [VRE]:** layers (hook, emotion/share driver, retention structure, format, topic, share-trigger, distribution), then counterfactual "remove it, does it still pop?", then replicability check, then principle applied to our niche.
**IG diagnosis [IG]:** reach, follow-conversion (views high/follows low = profile problem), retention/sends, sustainability. Reels = discovery, carousels = saves/authority, Stories = retention.

## 11. Where the skills disagree
- Length: SFS says 15-35s (~75 words); RS says 30-45s with max 2 points; Both say cut hard. Suggested: 20-35s, 2-3 points.
- Captions: SFS/MV say burn captions from word one (80-85% muted); RS and the user's rule differ. OUR RULE (CLAUDE.md): no auto-generated captions (Whisper mangles Malayalam/Manglish). Use hand-written short on-screen text only (hook plus key lines) to serve the muted-first goal.
- Hook openers: HW/SFS fine with "I"/story hooks; RS forbids opening with "I".
- Eye contact patching: TH says Descript Eye Contact patches a read, not a performance; MV lists Captions.ai eye correction as a tool. Prefer memorized map and real eye contact.
- Avatars: MV lists AI avatars for explainers; TH/MV both say authentic founder content should be filmed (we film the host).
- Hook strategy: SFS/HW push many variants and testing; VRE warns one data point is an anecdote, so test across several posts.
- CTA: RS prefers "Comment WORD and I'll send you X"; SFS prefers save/share/follow tied to value; IG prefers sends. Use comment-keyword only with a real deliverable.
- Bold claim vs curiosity gap: SFS says bold claims give faster early retention, curiosity builds suspense; HW says choose by goal. No single winner.
- Hook templates: HW says templates go stale and to use mechanisms; the templates in section 3 are starting scaffolds only, rewrite fresh in the host's voice.
